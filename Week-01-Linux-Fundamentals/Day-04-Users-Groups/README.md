# Day 04 - Linux Users and Groups

## Objective

Understand Linux user and group management, user permissions, and access control mechanisms.

---

## Topics Covered

- User Accounts
- Groups
- User Management Commands
- Group Management Commands
- Permission Assignment

---

## Commands Practiced

```bash
whoami
id
useradd
passwd
usermod
groupadd
groups
```

---

## Key Learnings

- Creating and managing users
- Understanding primary and secondary groups
- Assigning permissions using groups
- Managing user authentication

---

## Outcome

Successfully managed users and groups while understanding Linux access control concepts.
