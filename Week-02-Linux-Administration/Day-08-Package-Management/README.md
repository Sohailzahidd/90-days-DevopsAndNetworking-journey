# Day 08 - Package Management

## Objective

Learn how software packages are installed, updated, and removed in Linux.

---

## Topics Covered

- Package Repositories
- Package Installation
- Package Updates
- Package Removal

---

## Commands Practiced

```bash
apt update
apt upgrade
apt install
apt remove
apt search
dpkg -l
```

---

## Key Learnings

- Managing software repositories
- Installing applications
- Updating system packages
- Removing unused software

---

## Outcome

Successfully managed Linux software packages using package management tools.
