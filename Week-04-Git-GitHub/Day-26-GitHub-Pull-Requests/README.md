# 🚀 Day 26 - GitHub Pull Requests

## Objective

Learn how GitHub Pull Requests work and understand the complete collaboration workflow used by software development teams.

---

## Topics Covered

- Feature Branch
- Push Branch
- Pull Request
- Code Review
- Merge Pull Request
- Delete Branch

---

## Why Pull Requests?

Pull Requests allow developers to review code before merging it into the main branch.

This helps teams:

- Improve code quality
- Catch bugs early
- Collaborate efficiently
- Automate testing using CI/CD

---

## Commands Practiced

### Create Branch

```bash
git switch -c feature-pull-request
```

### Push Branch

```bash
git push -u origin feature-pull-request
```

### Merge Pull Request

Performed using the GitHub web interface.

---

## Key Learnings

- Pull Requests improve collaboration.
- Code reviews reduce bugs.
- GitHub keeps a complete history of changes.
- Pull Requests integrate well with CI/CD pipelines.

---

## DevOps Connection

Pull Requests are widely used in:

- GitHub Actions
- Jenkins Pipelines
- Azure DevOps
- GitLab CI/CD
- Infrastructure as Code
