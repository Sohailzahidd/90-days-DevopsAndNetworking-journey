# Day 16 - IP Addressing

## Topics Covered

- IP Address
- IPv4
- IPv6
- Public IP
- Private IP
- Static IP
- Dynamic IP
- Loopback Address

## Commands Practiced

ip a
hostname -I
ip route
ping 127.0.0.1 -c 4
curl ifconfig.me

## Key Learnings

- IP addresses identify devices on a network.
- IPv4 uses 32-bit addresses.
- IPv6 uses 128-bit addresses.
- Public IPs are Internet-facing.
- Private IPs are used inside local networks.
- 127.0.0.1 refers to the local machine.
