# Day 16 - IP Addressing

## Objective

Learn how devices are identified on a network using IP addresses and understand the different types of IP addressing.

---

## What is an IP Address?

An IP (Internet Protocol) Address is a unique identifier assigned to a device connected to a network. It allows devices to communicate with each other.

Example:

192.168.1.10

---

## IPv4 Addressing

IPv4 is the most commonly used version of Internet Protocol.

### Characteristics

* Uses 32-bit addresses
* Written in dotted decimal format
* Supports approximately 4.3 billion unique addresses

Example:

192.168.1.10

---

## IPv6 Addressing

IPv6 was introduced to solve the address exhaustion problem of IPv4.

### Characteristics

* Uses 128-bit addresses
* Provides a significantly larger address space
* Supports modern Internet growth

Example:

2001:db8::1

---

## Public IP Address

A Public IP Address is accessible over the Internet and is assigned by an Internet Service Provider (ISP).

Examples:

* Websites
* Cloud Servers
* Public APIs

---

## Private IP Address

Private IP Addresses are used within local networks and are not directly accessible from the Internet.

Private Address Ranges:

* 10.0.0.0 – 10.255.255.255
* 172.16.0.0 – 172.31.255.255
* 192.168.0.0 – 192.168.255.255

---

## Static IP Address

A Static IP remains unchanged and is commonly used for servers and networking devices.

Benefits:

* Consistent connectivity
* Easier remote access
* Reliable service hosting

---

## Dynamic IP Address

A Dynamic IP is automatically assigned by a DHCP server and may change over time.

Benefits:

* Easy management
* Efficient address allocation
* Common in home and office networks

---

## Loopback Address

The Loopback Address is:

127.0.0.1


It allows a device to communicate with itself for testing and troubleshooting purposes.

---

## Importance of IP Addressing

IP addressing enables:

* Device identification
* Communication between systems
* Internet connectivity
* Routing and traffic management

---
Key Learnings
Every device requires an IP address to communicate.
IPv4 and IPv6 are the two major Internet Protocol versions.
Public and Private IP addresses serve different purposes.
Static and Dynamic IPs are assigned differently.
Loopback addresses are useful for testing.
Outcome

Developed a strong understanding of IP addressing concepts and their importance in networking, cloud computing, and DevOps environments.
